### Запуск

1. Переходим в папку QtRelease.
2. Запускаем Course_work.

P.S. (Для корректного отображения GUI нужно использовать Ubuntu 22.04.5 LTS x86_64. Если необходимо поменять данные для подключения к БД, меняем файл configDB.json. Чтобы протестировать работу приложения необхожимо связаться с автором, чтобы он запустил облачный сервер с БД :)
